# Current communication architecture

CAN RX ISRs hand standard data frames to `Can_IsrRxIndication`; protocol and XCP execution run in task context. `Can` owns all application HAL CAN submissions and correlates three hardware mailbox completions using TXOK, errors and the 100 ms abort; it confirms only success (`CanIf_TxConfirmation(PduId)`) and counts failures in `Can_TxErrors`. `CanIf` maps 6 RX and 14 TX PDUs from `CanIf_Cfg.c` to the upper layers and applies the per-PDU mode (`CanIf_SetPduMode`), keeping the diagnostic PDUs always online. `PduR` routes Com interface PDUs and diagnostic TP data. `CanTp` is the ISO 15765-2 layer and moves data through the PduR TP buffer API directly into and out of the Dcm buffers; Dcm never sees PCI bytes.

See the current [ZGW CAN contract](../modernization/ZGW_ELC_CAN_CONTRACT.md), [module coverage](../autosar/BSW_FUNCTIONAL_COVERAGE.md), [alignment review](../autosar/AUTOSAR_LAB_ALIGNMENT.md) and [validation](../modernization/ELC_VALIDATION_RESULTS.md). Wire diagnostics are extended 710 with RX N_TA 58 and TX N_TA F0; CanTp (and the FBL) additionally accept flow control addressed with N_TA 41, the tester address ZGW uses outside a forwarded request (source-derived from ZGW `CanTp.c`, **not bus-verified**). CanTp timing: BS 8, STmin 5 ms, N_As/N_Ar/N_Bs/N_Cr 1 s, N_WFTmax 3; FF_DL <= 6 is ignored and reserved STmin values mean 127 ms. Application IDs/DLCs and signal meanings remain unchanged. Telemetry comes from a coherent SMon publication through `Com_SendSignal`, and completion versions protect newer queued samples.

NM3 is 3FF/DLC1 with the retained ELC bit6 policy and 200 x 5 ms loss timeout. `CanNm` posts `ComM_Nm_NetworkMode/BusSleepMode`; `CanSM` follows bus-off/mode indications from `CanIf` and sets the PDU modes; `ComM` owns the UDS `28` gates (`ComM_IsTxAllowed/IsRxAllowed`, `Com_SetRxAllowed/SetTxAllowed`). Normal TX is inhibited without a network request or while bus-off. Diagnostic communication remains available. No unsupported NM transmit frame or NM-only MCU standby was introduced. Physical bus timing/FC correlation remains unverified.
