# ELC BSW functional coverage — 2026-10-24

This is a configured, AUTOSAR-style subset for STM32F103C8Tx, not a formal AUTOSAR Classic implementation or compliance claim. It follows the ZGW shape (static configuration, direct module calls, AUTOSAR type and API names) and has **no RTE, DET or MemMap**. **Source-implemented, Cortex-M3 compiled and assertion-host-tested** are separate from **hardware-verified**; no hardware validation was performed. The rule set, the review findings and the behavior changes of this revision are in [AUTOSAR_LAB_ALIGNMENT.md](AUTOSAR_LAB_ALIGNMENT.md); this file is the per-module record.

ZGW reference paths are relative to `D:/GitHub_Repos/ZGW/ZGW/ZGW_APP` and are read-only; every implementation dependency is inside ELC. `tools/audit_sources.py` inventories 97 maintained source/linker files with hashes in `docs/modernization/SOURCE_INVENTORY.json` and enforces the layering and ownership rules listed in the alignment record.

Paths are relative to `ELC_APP/BSW` unless noted.
