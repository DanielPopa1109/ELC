# ELC BSW functional coverage — 2026-10-19

This is a configured, AUTOSAR-style subset for STM32F103C8Tx, not a formal AUTOSAR Classic implementation or compliance claim. No RTE, DET or MemMap was introduced. **Source-implemented, Cortex-M3 compiled and assertion-host-tested** are separate from **hardware-verified**; no hardware validation was performed. The existing working tree already contained unfinished communication/FBL work, which was extended rather than discarded.

ZGW reference paths below are relative to `D:/GitHub_Repos/ZGW/ZGW/ZGW_APP`; references are read-only. All implementation dependencies are inside ELC. `tools/audit_sources.py` inventories 74 maintained source/linker files with hashes in `docs/modernization/SOURCE_INVENTORY.json`.
